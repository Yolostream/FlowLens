# Security policy

## Supported versions

Until version 1.0, security fixes are applied to the latest released version.

## Reporting a vulnerability

Please do not create a public issue. Use GitHub private vulnerability reporting if enabled for this repository. Otherwise contact the repository owner privately through the contact method listed on their GitHub profile.

Include:

- affected version or commit;
- reproduction steps using synthetic data;
- expected impact;
- suggested remediation, if known.

Do not include credentials, private exported solutions or corporate data.

## Scope note

FlowLens performs static pattern analysis. A finding is not confirmation of a vulnerability, and the absence of findings is not a security guarantee.
